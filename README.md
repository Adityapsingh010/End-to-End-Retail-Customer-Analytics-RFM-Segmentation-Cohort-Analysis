This project is an end-to-end Data Analytics portfolio piece designed to solve real-world e-commerce challenges.
Rather than just building standard charts, this dashboard is focused on actionable business intelligence—specifically identifying 
who the most valuable customers are and tracking whetherthey continue to purchase over time.
By combining Python for data wrangling, SQL for complex feature engineering, and Power BI for interactive visualization, this project demonstrates a complete, Standard analytics pipeline.

Business Value & Key Metrics:
I built this dashboard to answer the critical questions that drive e-commerce revenue:

RFM Customer Segmentation: Who are our 'Champions' and who is 'At Risk' of churning?
Cohort Analysis: What is our month-over-month customer retention rate?
Global Sales Performance: Which geographic markets drive the most revenue?
Inventory Focus: What are the top 10 products we need to keep in stock?

End-to-End Data Workflow:

Data Preparation (Python): Handled missing values, standardized formats, and cleaned transactional anomalies.
Data Modeling (SQL): Wrote advanced queries utilizing CTEs and Window Functions to calculate Recency, Frequency, and Monetary (RFM) scores,
and to generate the relative month indexes required for Cohort Analysis.
Visualization (Power BI): Developed a dynamic relational model with synchronized slicers, custom DAX measures
(e.g., Repeat Purchase Rate), and a clean, minimalist UI/UX optimized for executive decision-making.
